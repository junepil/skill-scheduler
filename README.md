# skill-scheduler

Register any Claude Code skill (user or plugin) to run on a cron schedule via macOS launchd.

## Requirements

- macOS
- `claude` CLI installed at `~/.local/bin/claude`
- Bun 1.x
- macOS notification permission for Script Editor / osascript
